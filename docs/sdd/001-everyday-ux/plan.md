# برنامه‌ی فنی ۰۰۱ — کار روزانه، جست‌وجو، راهنما

## تصمیم‌های فنی

- **بدون وابستگی جدید.** پالت فرمان و نمای «امروز» با React/Tailwind موجود ساخته می‌شوند.
- **داده از state موجود.** هیچ API جدید لازم نیست؛ کارت‌های «امروز» از همان snapshot ساخته می‌شوند تا با RBAC و وضعیت سرور هم‌خوان بمانند.
- **منطق قابل‌تست جدا می‌شود.** محاسبه‌ی «کارهای امروز» و رتبه‌بندی نتایج جست‌وجو در `src/utils/` به‌صورت تابع خالص، با تست واحد؛ کامپوننت فقط نمایش.
- **دسترسی‌پذیری در لایه‌ی مشترک.** skip-link، focus trap و اعلام وضعیت در `AppShell`/کامپوننت مشترک یک‌بار پیاده می‌شود، نه در هر نما.

## فایل‌های درگیر (پیش‌بینی)

| فایل | تغییر |
| --- | --- |
| `src/utils/todayTasks.ts` (جدید) | تابع خالص تولید کارهای امروز + اولویت‌بندی |
| `src/utils/searchIndex.ts` (جدید) | ساخت ایندکس و جست‌وجوی مشتری/سفارش/تیکت |
| `src/utils/*.test.ts` | تست منطق بالا |
| `src/components/TodayView.tsx` (جدید) | نمای پیش‌فرض «امروز» |
| `src/components/CommandPalette.tsx` (جدید) | پالت جست‌وجو با صفحه‌کلید |
| `src/components/AppShell.tsx` | skip-link، `main`، اتصال پالت، راهنمای منو |
| `src/App.tsx` | تب پیش‌فرض پس از ورود، اتصال نماها |
| `src/index.css` | `focus-visible` سراسری، `prefers-reduced-motion` |

## ریسک‌ها

- **افزایش شلوغی به‌جای سادگی.** کاهش: حداکثر ۵ کارت و پنهان‌کردن کارهای بی‌اقدام.
- **جست‌وجوی کند با داده‌ی زیاد.** کاهش: ایندکس ساده‌ی نرمال‌شده و محدودیت ۲۰ نتیجه؛ اگر لازم شد، debounce.
- **شکستن رفتار فعلی تب‌ها.** کاهش: نمای «امروز» به‌عنوان تب اضافه می‌شود، تب‌های موجود دست‌نخورده می‌مانند.

`npm run typecheck` · `npm test` (تست‌های جدید منطق) · `npm run build` · بازبینی صفحه با صفحه‌کلید و در عرض ۳۶۰px.
