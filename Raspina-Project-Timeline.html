🕐

بازه زمانی کل: ۶ هفته (۱.۵ ماه) — پیش‌نیاز: دسترسی API سایت‌ها

سریع‌ترین بخش پروژه. اگر APIهای سایت‌های راسپینا از پیش مستند باشند یا دسترسی admin وجود داشته باشد، این بازه به ۴.۵ هفته کاهش می‌یابد.

  • 📊
    Schema مشتری: فیلدهای هویتی، علایق، تاریخچه خرید، امتیاز فعلی و سطح عضویت

  • ⭐

  • 🔁

  • 👁️

  • 📋

  • 📊

  • 📱
    واکنش‌گرا (PWA): کاملاً روی موبایل بدون نصب

ربات فروشگاهی تلگرام راسپینا

فروشگاه کامل در تلگرام با دسته‌بندی، لیست محصولات، قیمت و لینک خرید — اتصال زنده به سایت

🕐

بازه زمانی کل: ۳ هفته (۲۱ روز) — پیش‌نیاز: Telegram Bot Token + API سایت

سریع‌ترین پروژه از نظر پیاده‌سازی. اگر API محصولات سایت مستند باشد، در ۱۵ روز کاری قابل تحویل است.

🎯

هدف: کاربر بدون باز کردن سایت، هر کاری که می‌خواهد را در تلگرام انجام دهد

  • مشاهده همه دسته‌بندی‌ها با دکمه‌های اینلاین زیبا
  • مشاهده محصولات هر دسته با عکس، قیمت و توضیحات
  • لینک مستقیم خرید هر محصول از سایت
  • جستجوی محصول بر اساس نام یا ویژگی
  • مشاهده تخفیف‌ها و پیشنهادات روز
  • ثبت سفارش و پیگیری از درون تلگرام
۱ راه‌اندازی ربات و اتصال API روز ۱ تا ۵

ثبت ربات در BotFather، ساخت زیرساخت اتصال، دریافت و کش کردن محصولات از API سایت.

  • 🤖
    Bot Setup: راه‌اندازی Python-Telegram-Bot یا Aiogram (Async)
  • 🔗
    اتصال به WooCommerce/API سایت: دریافت دسته‌بندی‌ها، محصولات، موجودی و قیمت
  • ⚡
    Cache هوشمند: ذخیره موقت محصولات برای سرعت بالا — Refresh هر ۱ ساعت
۲ طراحی UX و منوی دسته‌بندی روز ۶ تا ۱۲

طراحی کامل جریان گفتگو با دکمه‌های اینلاین، نمایش دسته‌بندی‌ها در صفحه اول، و پیمایش محصولات.

  • 🗂️
    منوی اصلی (Inline Keyboard): دسته‌بندی‌ها با آیکون و تعداد محصول
  • 🖼️
    کارت محصول: عکس محصول + نام + قیمت + موجودی + دکمه «مشاهده در سایت»
  • 📄
    Pagination: نمایش ۱۰ محصول در هر صفحه با دکمه‌های قبلی/بعدی
  • 🔍
    جستجوی متنی: تایپ نام محصول → نتایج فوری
۳ امکانات پیشرفته + تست و تحویل روز ۱۳ تا ۲۱

اتصال به سیستم سفارش‌دهی، پیگیری، اطلاع‌رسانی تخفیف و تست کامل با کاربران واقعی.

  • 🛒
    پیگیری سفارش: وارد کردن کد سفارش → وضعیت از سایت
  • 🔔
    اطلاع‌رسانی تخفیف: Channel Broadcast برای اعضا
  • 👤
    اتصال به CRM: ثبت هر تعامل تلگرامی در پروفایل مشتری

    تست UAT + رفع باگ + آموزش مدیر ربات

ربات هوشمند اینستاگرام (AI-Powered)

دو بخش مجزا: (الف) پاسخ خودکار هوشمند به دایرکت‌ها با AI — (ب) داشبورد تحلیلی اینستاگرام با گزارش روزانه و هفتگی

🕐

بازه زمانی کل: ۵ هفته — مهم‌ترین پیش‌نیاز: دسترسی Instagram Graph API (Business Account) + کلید AI API

این پروژه به دلیل محدودیت‌های Meta API و نیاز به آموزش و تنظیم مدل AI، زمان بیشتری نیاز دارد. دقت بالای پاسخ‌دهی مستلزم دوره Fine-tuning و آزمون مکالمات واقعی است.

📩 بخش الف: پاسخ هوشمند به دایرکت‌ها با هوش مصنوعی
۱ راه‌اندازی Instagram Graph API + دریافت مجوز روز ۱ تا ۵

تبدیل پیج به Business Account (در صورت نیاز)، راه‌اندازی Meta Developer App، دریافت Access Token و اتصال Webhook.

  • 🔑
    Meta App Setup: ثبت اپ، تأیید Business Verification، دریافت توکن‌های Long-lived
  • 📡
    Webhook: دریافت لحظه‌ای دایرکت‌های جدید (messages_read, message_echoes)
  • ⚠️
    بافر زمانی برای تأیید Meta: گاهی ۱-۲ روز زمان می‌برد
۲ ساخت Knowledge Base از محصولات راسپینا روز ۶ تا ۱۰

ساخت پایگاه دانش کامل از تمام محصولات، دسته‌بندی‌ها، قیمت‌ها و سیاست‌های برند برای تغذیه مدل AI.

  • 📚
    Crawl محصولات: دریافت تمام محصولات با قیمت، توضیح، دسته، سایز، رنگ از API سایت
  • 🧠
    RAG (Retrieval-Augmented Generation): ذخیره اطلاعات در Vector Database (Pinecone/Chroma)
  • ✍️
    System Prompt دقیق: تعریف شخصیت ربات، لحن برند، قوانین پاسخ و محدودیت‌ها
۳ اتصال AI و تنظیم دقت پاسخ‌دهی روز ۱۱ تا ۱۸

اتصال مدل هوش مصنوعی (GPT-4o یا Claude)، تنظیم منطق شناسایی پست محصول ارسال‌شده در دایرکت، و ارسال پاسخ ۲–۱۰ ثانیه‌ای.

  • 🤖
    AI Pipeline: دریافت پیام → تشخیص محصول/سؤال → جستجو در Knowledge Base → تولید پاسخ
  • 🖼️
    تشخیص پست محصول: هنگام فوروارد کردن پست محصول به دایرکت، ربات محصول را شناخته و قیمت + لینک می‌فرستد
  • ⏱️
    تضمین ۲–۱۰ ثانیه: معماری Async + موازی‌سازی
  • 🔁
    Fallback هوشمند: سؤالاتی که AI جواب نمی‌داند → انتقال به کارشناس انسانی
۴ تست با مکالمات واقعی و رفع اشتباهات روز ۱۹ تا ۲۵

مهم‌ترین مرحله: آزمون ۵۰+ نوع سؤال واقعی مشتریان، رفع خطاهای پاسخ، بهبود System Prompt.

  • 🧪
    تست ۵۰+ سناریو: قیمت محصول، موجودی، رنگ‌ها، سایزها، نحوه ارسال، مرجوعی و...
  • 🛡️
    Guardrails: جلوگیری از پاسخ‌های اشتباه (قیمت شومیز ≠ شلوار)
  • 📊
    Log ثبت تمام مکالمات: برای بهبود مستمر و آموزش
📊 بخش ب: داشبورد تحلیلی اینستاگرام + گزارش‌دهی هوشمند
۵ اتصال به Instagram Insights API روز ۲۰ تا ۲۴ — موازی با بخش الف

  • 👁️

  • 🛒
    Shopping Insights: کلیک لینک، بازدید محصول و فروش از اینستاگرام
  • ⏰
    Optimal Posting Time: بهترین ساعت پست‌گذاری بر اساس فعالیت مخاطبان
۶ گزارش روزانه + هفتگی با تحلیل AI روز ۲۵ تا ۳۰

تولید خودکار گزارش روزانه و هفتگی با تحلیل هوشمند و توصیه‌های اقدام توسط AI.

  • 📊

  • 💡
